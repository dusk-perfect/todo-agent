# 小明智能体 · 待办清单编程题

请把小明改造成一个待办清单智能体，让用户用中文对话管理自己的任务。项目已经提供聊天界面、可持久化的任务 API 和 DeepSeek 客户端。

模板初始状态下，无论你说什么，小明都只会回复「你好，欢迎使用小明智能体」；本仓库把它改造成了能用中文管待办的助手，实现说明见下文。

## 基础要求

请让用户能通过聊天完成创建、查看、标记完成和删除这四种操作。任务应保存到本地，刷新页面或重启服务后仍可查询。

可以从 [server/agent.ts](server/agent.ts) 开始，在这里接收对话历史并返回本轮回复。

任务接口的路径、字段和返回值见 [OpenAPI 说明](server/openapi.yaml)。

下面是一段验收对话。

| 用户对小明说     | 预期结果                                   |
| ---------------- | ------------------------------------------ |
| 帮我记一下买牛奶 | 新增待办「买牛奶」                         |
| 再记一条取快递   | 清单里多了一条「取快递」                   |
| 我有哪些任务？   | 列出两条任务，并能看出各自的完成状态       |
| 牛奶买好了       | 把「买牛奶」标记为已完成，「取快递」仍待办 |
| 取快递这条删掉吧 | 删除「取快递」                             |
| 再给我看看清单   | 只剩已完成的「买牛奶」                     |

本仓库的实际表现：创建后会追问一次要不要加备注；清单按完成日期分组，标题前写「11-27 内完成」，同一天的任务合并成一组。

完成的说法认得比较宽：「已经完成买牛奶」「完成了买牛奶」「牛奶买好了」「搞定了」「写好了」「都做完了」都能听懂，不会把完成汇报当成一条新任务记进去。

## 可选扩展

以下扩展功能可选做，有的任务描述刻意写得比较模糊。

- 回答「今天有哪些任务到期？」
- 创建并管理子任务
- 改进清单的展示，让用户更容易看出哪些任务还需要处理。
- 为任务增加优先级和工作量（如小、中、大）。
- 你认为合适的任何功能或优化

## 实现说明

### 对话能力

基础四项（创建、查看、标记完成、删除）都已实现，用日常说法即可触发。在此基础上做了这些：

- **创建后追问备注**：新建一条后问「需要给「买牛奶」备注说明吗？」，答「没有」就结束；答具体内容（比如「要三元的纯牛奶，高优先级，明天内完成」）会拆成备注、优先级、完成日期分别写进任务。
- **优先级与工作量**：各三档，创建时可以直接说，事后可以改（「把买牛奶设为低优先级」）。
- **完成日期**：认「今天」「明天」「下周三」「3月5日」；「周末」「月底」「下个月初」按真实日历落到具体某天；说「上午」「中午」「下午」「晚上」等同当天，说「现在」「等下」这类当下词也按当天算；跨年说「1月5日」会算到明年。
- **只看某天**：「今天有哪些任务？」只列当天要做的。
- **清单分组**：按「MM-DD 内完成」分组，同一天归在一起、日期只写一次，没排期的放最后一组；全部做完时抬头写「共 N 项，都已完成」。
- **更多动作**：把任务标回待办、修改任务名、删除全部任务、清空已完成、直接改完成日期（「把买牛奶设为明天内完成」）。
- **该问就问**：说不清指的是哪一条就反问；刚问完备注时，只有明确说「要补充」才并入上一条，其余一律算新任务。
- **不乱拆**：一句话里确实有几件事才拆成多条，「和」是介词时不拆（「我要和朋友出去玩」是一件事）；标题会去掉「我」「等下」这类不是事情本身的开头。

### 产品化补充

- **记忆**：对话按会话存在本机，刷新或重启后能接着聊；页头的「清空对话」只清对话、不动任务，而且要按两次才真清。
- **多用户**：首次打开在浏览器生成一个匿名身份，各人的清单和对话分开存；没带身份的请求仍走原来的单用户清单，评测脚本不受影响。
- **提醒**：「下午三点半」这类时刻会单独记下来，页面上方按已过期、今天、一小时内分级提示，授权后到点再弹一次浏览器通知。

### 规则优先，模型兜底

默认走本地规则引擎，配了 `DEEPSEEK_API_KEY` 后，规则接不住的长句才交给模型；请求 15 秒超时、不重试，超时或校验不过就退回规则。不配 Key 也能完成上面全部验收动作。

可选的日历冲突提醒：把自己的 `.ics` 导出文件放到 `data/calendar.ics`（或用 `CALENDAR_ICS_PATH` 指定），新建任务与已有日程撞在同一天时会提一句；没有这个文件就完全不做提醒。格式示例见 [examples/calendar.example.ics](examples/calendar.example.ics)。

## 快速开始

安装 Node.js 24.12 或更高版本，在项目根目录运行以下命令。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:3000>，发送一句话即可看到回复。`npm run dev` 会先构建前端再启动服务，改动服务端代码会自动重启；只跑构建好的产物可以用 `npm start`。

接入模型时，把 `.env.example` 复制为 `.env`，填写自己的 `DEEPSEEK_API_KEY`，再重启服务。详细步骤见[本地开发指南](GETTING_STARTED.md)。

### 环境变量

| 变量                | 默认值              | 说明                                     |
| ------------------- | ------------------- | ---------------------------------------- |
| `DEEPSEEK_API_KEY`  | 空                  | 留空则只用规则引擎，不产生模型费用       |
| `DEEPSEEK_MODEL`    | `deepseek-flash`    | 使用的模型                               |
| `PORT`              | `3000`              | 服务端口                                 |
| `DATA_DIR`          | `data`              | 数据根目录：多用户清单、对话、日历都在这 |
| `TASKS_FILE`        | `data/tasks.json`   | 单用户模式下任务文件的位置               |
| `CALENDAR_ICS_PATH` | `data/calendar.ics` | 日历文件；不存在就不做日历提醒           |

演示或联调时把 `DATA_DIR` 指向临时目录，就不会写进真实清单。

### 接口一览

| 方法   | 路径                             | 说明                           |
| ------ | -------------------------------- | ------------------------------ |
| POST   | `/api/chat`                      | 发送对话历史，返回本轮回复     |
| GET    | `/api/tasks`                     | 列出任务                       |
| POST   | `/api/tasks`                     | 新建任务（只收 `title`）       |
| PATCH  | `/api/tasks/{id}`                | 改标题或完成状态               |
| DELETE | `/api/tasks/{id}`                | 删除任务                       |
| GET    | `/api/reminders`                 | 已过期、今天、一小时内三类提醒 |
| GET    | `/api/conversations/{sessionId}` | 取回某次会话的最近若干轮       |
| DELETE | `/api/conversations/{sessionId}` | 清空某次会话                   |

带 `x-user-id` 的请求按该身份的清单处理，不带就落到默认单用户清单；带 `x-session-id` 的对话才会落盘。完整定义见 [server/openapi.yaml](server/openapi.yaml)。

### 目录结构

```
server/agent.ts        对话入口：串联追问状态、规则、模型与格式化
server/agent/intent.ts 规则引擎：中文意图识别
server/agent/date.ts   相对日期、时段与时刻解析
server/agent/llm.ts    模型规划与提示词
server/agent/followup.ts 创建后的备注追问与日期追问
server/agent/format.ts 清单渲染与日期分组
server/agent/calendar.ts iCalendar 日历解析
server/users.ts        匿名身份与数据目录
server/conversations.ts 对话记忆
server/reminders.ts    到期提醒计算
```
